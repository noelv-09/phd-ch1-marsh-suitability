# License — decision deferred

This repository is currently **private** and unlicensed.

## Why no LICENSE file yet

A formal open-source license will be selected at the time of public release,
in consultation with:

- UNM Office of Research Integrity (for any IP / data-rights considerations
  tied to grant funding)
- Coastal-tribal partners (any data products related to Skagit Bay / Fir Island
  Farm with tribal interest will be reviewed against the
  [CARE Principles for Indigenous Data Governance](https://www.gida-global.org/care))
- Dissertation committee (preferred license for reproducibility supplements)

## Candidate licenses (to be reviewed before release)

| License | Notes |
|---------|-------|
| **MIT** | Permissive, simple, widely used for academic code |
| **Apache 2.0** | Permissive with explicit patent grant; preferred for derived work that may be commercialized |
| **BSD 3-Clause** | Permissive, prohibits use of author's name to endorse derived works |
| **CC-BY 4.0** | Better fit for derived data tables, figures, and the methods documentation rather than code |
| **No license / "all rights reserved"** | Default until publication; collaborators must request access in writing |

## Current status

Until a license is selected and committed, **all rights reserved**.
Sharing of this code with anyone outside the immediate dissertation committee
requires written permission from the author.
